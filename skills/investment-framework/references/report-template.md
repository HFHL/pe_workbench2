# 投资框架报告模板（七节）

报告是 `analysis-state.json` 的视图。每节引用状态里的 ID，读者可以顺着 ID 回到证据；不要让报告和状态各说一套。

## 写作前先记住三条

1. **目标价是模型输出，倍数是输入。** `10x → 11x` 不等于“目标价 +10%”；还要看 ARR/EPS 基数、汇率、股数、净现金。倍数必须写清口径与期间，如 `11x 2026E ARR`，不能简称“PE”。
2. **不同方法不能写成连续目标价。** DCF 的 1560 和 ARR 倍数法的 320/458 是两种模型；要并列、标“不可比”、给 bridge，不能写 `1560 → 320 → 458`。
3. **归因只列进入公式的驱动。** 不在某个 `V.drivers` 里的假设（例如 ARR 倍数法里的 A3 利润率）可以解释观点，不能解释目标价变化。

## 写作规则

- 结论先行：第二节先给判断，再给依据。
- 正文写业务名称、年份和自然语言路径，不写裸单元格坐标；坐标放证据定位。
- 数字带单位、期间、口径；未知写“未确定”，不写 0。
- 图表只在有真实数据时生成；没有就写缺口，不画假图。
- 跟踪记录只追加，不覆盖历史；跨方法不写“目标价 A → B”，只写“方法 X 为 A；方法 Y 为 B，不可比”。
- 同一数据截止日内反向修正，必须写新增的非推断证据和 `stability_note`；只凭“人工判断偏高/偏低”或现价距离调整，标 `needs_review`。
